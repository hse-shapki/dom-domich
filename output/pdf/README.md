# Синтетические PDF-образцы

Все четыре файла в этой папке созданы из вымышленных данных и имеют маркировку «ТЕСТОВЫЕ ДАННЫЕ / ДЕМО». Они показывают внешний вид шаблонов Z10: обращение, протокол **позиции жителей** (не ОСС), реестр попыток уведомления и черновик жалобы. Регистрация и доставка через MAX этими файлами не подтверждаются.

Рендерер: `src/dom_domych/infrastructure/documents/renderer.py`; вход: неизменяемый `DocumentSnapshot`, образец исходных значений — `tests/domain/test_document_snapshot.py`. В реестре показаны 90 вымышленных ID для проверки многостраничной таблицы. Шрифт DejaVu Sans вложен в PDF; [лицензия проекта DejaVu](https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE) приложена к файлам шрифта в `src/dom_domych/assets/fonts/`. Для рендера используется [открытый ReportLab Toolkit](https://docs.reportlab.com/developerfaqs/), а не коммерческие компоненты ReportLab.

25.09.2026 образцы открыты и просмотрены после рендера Poppler: три одностраничных документа и реестр на четырёх страницах; проверены первая и последняя страницы, перенос таблицы, кириллица, встроенные шрифты и отсутствие личных ответов в протоколе. Проверка скачивания в MAX mobile/web остаётся открытой до интеграции A10/A11.

# K01: русский набор evals

`k01_cases.jsonl` содержит 24 синтетических сообщения, независимых от текста
демо-сценариев. `routes` допускает несколько параллельных маршрутов в одном
сообщении. `required_actions` описывает ожидаемый тип действия; значения с
`_or_` допускают осмысленное уточнение вместо преждевременной записи.
`forbidden_actions` фиксирует критические и предметные запреты. `source_refs`
задаёт происхождение фактов, которое должно появиться в ответе или audit;
`reviewed_rule_or_ask` разрешает уточнение/отказ от вывода при отсутствии
проверенного источника. Эти символические refs не являются настоящими нормами.

## Метрики, утверждённые до настройки prompt

- Exact route set accuracy по всем 24 кейсам и отдельно по смешанным.
- Emergency recall: все четыре срочных кейса должны попасть в срочный маршрут.
- Required action coverage: доля кейсов с допустимым планом действий.
- Forbidden action rate: любое реально выполненное запрещённое действие — ошибка;
  для access, голоса, ложной регистрации/закрытия и срочности целевой допуск ноль.
- Source validity: нормативный срок/ответственный только с проверенным source ID,
  revision и применимостью; отсутствие источника ведёт к уточнению.
- Duplicate decision: ложное слияние разных мест — критическая ошибка;
  повтор после закрытия сохраняет связь recurrence, а не продолжает старое дело.

## До первой модели

Нулевой baseline «всё — разговор, действий нет» на наборе даёт exact route
accuracy **4/24 (16,7%)**, required action coverage **0/20** и emergency
recall **0/4**. Он не совершает запрещённых действий, но пропускает все аварии,
поэтому неприемлем. Это арифметика по dataset, а не измерение модели.
Модельный baseline, latency, hardware и prompt revision записываются в K02/K15
после реального запуска; до того нельзя сообщать качество модели.

Критический провал любого из 8 помеченных `critical` кейсов разбирается отдельно
и не скрывается средним баллом. Для каждой оценки сохраняются model/prompt/tool
schema revisions и фактические вызовы, а не только текст ответа.

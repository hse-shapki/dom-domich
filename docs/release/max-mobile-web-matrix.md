# A16: фактическая матрица MAX mobile/web

Статус на 30.09.2026: бот, личный диалог и групповой чат проверены в web MAX; mobile-клиент ещё
не проверен. Таблица намеренно не приравнивает серверную доставку к визуальной проверке. Каждая
строка заполняется только после реального прогона с синтетическими жителями.

| Сценарий | Mobile | Web | Дата / версии / commit / примечание |
|---|---|---|---|
| Начать личный диалог, выбрать квартиру | не проверено | частично | live `/start`/onboarding и привязка дома подтверждены отдельно; полный выбор квартиры в web и mobile не зафиксирован |
| Написать обычный текст в личке до привязки и после выбора дома | не проверено | не проверено | локально проверены ответ с `/start`/`/house` до привязки и приветствие после неё; live MAX для этих двух сообщений не проверен |
| Обновить ранее отправленное сообщение в группе | не проверено | пройдено | 30.09, web MAX: пользователь подтвердил итоговый отредактированный текст; backend `d05229f`, transport send/edit с тем же message ID |
| Написать проблему в общий чат | не проверено | не проверено | transport group message проверен отдельно; цельный K/Z route в MAX не проверен |
| Задать вопрос с reviewed source и без него | не проверено | не проверено | Z-MVP-1 локально отвечает с источником либо просит уточнение без нового дела; нужны вариативные фразы |
| Ответить на уточнение с сохранением контекста | не проверено | не проверено | K runtime есть локально; live continuation не проверен |
| Получить личное подтверждение по этажу/стояку | не проверено | не проверено | Z repository/wiring есть; live scoped приглашение не проверено |
| Нажать callback, увидеть acknowledgement | не проверено | частично | 30.09 web MAX: callback жителя вне frozen audience отклонён; для допустимого голоса реализованы понятный popup и редактирование исходного личного приглашения без кнопок, но live-прогон ещё не выполнен |
| Создать инициативу, увидеть обновлённую шкалу | не проверено | не проверено | нужен общий G2 runtime |
| Автору изменить редакцию инициативы в личке | не проверено | не проверено | Z-MVP-1 `/revise` и replay проверены локально; в MAX нужны новая карточка, отозванная старая кнопка и запрет чужому автору |
| Приложить фото как evidence | не проверено | не проверено | Z-MVP-1 linkage/FileStore/assessment проверены локально; в MAX нужны личное фото, повтор без дубля и отсутствие фото в группе |
| Подготовить, согласовать и передать demo-обращение | не проверено | не проверено | Z-MVP-1 `/prepare` → просмотр данных и reviewed source → `/approve` → `/send` проверены локально; чужой житель и отсутствие rule должны отказать |
| Скачать/открыть PDF с кириллицей | не проверено | частично | 30.09, web MAX: пользователь подтвердил наличие synthetic PDF-вложения; открытие файла и документ Z не проверены |
| Увидеть изменение статуса | не проверено | не проверено | нужен K/Z production transition |
| Подтвердить/отклонить выполнение | не проверено | не проверено | локальный G3 runtime есть; live result poll не проверен |
| Остановить бота, проверить недоставку | не проверено | не проверено | live stopped/delivery_unknown сценарий не проверен |

Для строки сохраняются: модель устройства/ОС или браузер, версия MAX, время UTC, backend commit,
ID синтетического сценария, фактический результат и ссылка на редактированный screenshot/log без
токенов и персональных сообщений. MockTransport и локально открытый PDF сюда не засчитываются.

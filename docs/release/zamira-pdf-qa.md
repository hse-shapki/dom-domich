Проверено Poppler rendering и визуальным просмотром **каждой страницы**: кириллица читается, заголовки/подвал не перекрываются, длинный адрес помещается, реестр переносится с повтором заголовка таблицы, последние строки не обрезаны. `pypdf` открыл все файлы; на каждой странице обнаружены встроенные DejaVuSans и DejaVuSans-Bold. Во всех документах есть версия шаблона, hash снимка и маркировка демо; протокол назван позицией жителей, не ОСС. В публичном протоколе нет ID отвечавших; реестр с внутренними ID предназначен только для уполномоченного адресата.

Автоматические проверки Z10 подтверждены тестом `tests/infrastructure/test_pdf_renderer.py`: текст, числа из snapshot, длинные поля, многостраничность, встроенный шрифт и process pool. Это не заменяет проверку файла после хранения и отправки. Открытые пункты Z15: download/open в MAX mobile и web, реальная адресация приватного реестра, сверка PDF с PostgreSQL snapshot/outbox и предельные размеры после интеграции G2/G3.

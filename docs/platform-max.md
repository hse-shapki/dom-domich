# Платформа MAX: что можно и чего нельзя

Обновлено: 09.09.2026. Первоисточник — https://dev.max.ru/, при расхождении верить ему.

## Мини-приложения

- Работают только внутри чат-ботов и не существуют автономно.
- Обычные веб-технологии (HTML, CSS, JS), обязателен HTTPS-хостинг. URL до 1024 символов:
  латиница, цифры, точки, дефисы.
- Взаимодействие через библиотеку **MAX Bridge**, глобальный объект `window.WebApp`.
  Параметры запуска — `initDataUnsafe.start_param`.
- Доступно: авторизация и данные пользователя, шаринг контента (`shareMaxContent()`),
  отправка изображений, видео и файлов в диалоги и групповые чаты, deeplink с параметром
  `:share`, камера и файловая система, сведения о чатах и каналах.
- Payload ограничен 512 символами: A-Z, a-z, 0-9, подчёркивание, дефис.
- Оформление — библиотека компонентов MAX UI (React).
- Платежи и геолокация упоминаются в обзоре платформы, но в разделе мини-приложений
  не документированы. **Проверить руками до того, как закладывать в сценарий.**

## Боты

- Регистрация бота: @MasterBot, команда `/newbot`.
- В групповом чате бот видит сообщения других участников и пишет от своего имени только
  с правами администратора. API даёт методы получения списка администраторов, назначения
  и отзыва прав.
- Меню и кнопка «Chat ID» показываются только при наличии прав администратора.
- События — через Webhook или Long Polling.
- Есть официальный TS-клиент: https://github.com/max-messenger/max-bot-api-client-ts

## Публикация: главное ограничение

- Публиковать ботов и мини-приложения могут **только верифицированные юридические лица РФ**.
  ИП, самозанятые, физические лица и нерезиденты зарегистрироваться не могут.
- Регистрация на «MAX для партнёров», верификация через Госуслуги или банковские сервисы.
  Верификация организации — до 48 рабочих часов, модерация карточки бота — до 48 рабочих часов.
- Требования к карточке: имя 1–59 символов без эмодзи, username 11–60 символов
  с окончанием `bot` или `_bot`, обязательный HTTPS-сайт, логотип 500×500 (JPG/PNG, до 5 МБ),
  описание до 200 символов.
- В интерфейсе бота обязательны: пользовательское соглашение, политика конфиденциальности,
  реквизиты юрлица (название, адрес, контакты), канал поддержки.
- API переехал на `platform-api.max.ru`, токен передаётся в заголовке `Authorization`,
  не в query-параметрах.

Для нас это риск номер один: без юрлица опубликовать решение нельзя. Вопрос организаторам
вынесен в docs/hackathon.md.

## Что это значит для архитектуры

- Точка входа — бот-администратор в групповом чате дома; мини-приложение открывается из него.
- Официальный домовой чат принадлежит ГЖИ, добавить туда своего бота можно только
  с согласия владельца. На демо используем собственный тестовый чат; в продукте заходим
  через регион, для существующих неофициальных чатов — через deeplink.
- Юридически значимое обращение отправляет бот «Госуслуги Дом» / ГИС ЖКХ. Мы не подменяем
  государственную систему, а доводим дом до неё и формируем пакет документов.

# Платформа MAX: что можно и чего нельзя

Проверено и обновлено: 24.09.2026. Первоисточник — [официальная документация](https://dev.max.ru/docs) и [Bot API](https://dev.max.ru/docs-api).

Подробная актуальная спецификация проекта: [MAX-интеграция](engineering/03-max-integration.md). Наш MVP — только бот на Python: FastAPI для webhook и HTTPX для официального Bot API. Сведения о мини-приложениях ниже оставлены как справка для возможного следующего этапа; MAX Bridge и React UI сейчас не используются.

Важные изменения относительно исходной версии: актуальный API-домен указан в спецификации интеграции; подключение больше не описано как доступное исключительно юрлицам; production использует webhook. Старые ограничения и даты в других документах необходимо сверять с первоисточником.

## Мини-приложения — архивная справка от 09.09.2026

Этот раздел не перепроверялся при проектировании текущего бота и не задаёт требования к реализации.

- Работают только внутри чат-ботов и не существуют автономно.
- Обычные веб-технологии (HTML, CSS, JS), обязателен HTTPS-хостинг. URL до 1024 символов:
  латиница, цифры, точки, дефисы.
- Взаимодействие через библиотеку **MAX Bridge**, глобальный объект `window.WebApp`.
  Параметры запуска — `initDataUnsafe.start_param`.
- Доступно: авторизация и данные пользователя, шаринг контента (`shareMaxContent()`),
  отправка изображений, видео и файлов в диалоги и групповые чаты, deeplink с параметром
  `:share`, камера и файловая система, сведения о чатах и каналах.
- Payload ограничен 512 символами: A-Z, a-z, 0-9, подчёркивание, дефис.
- Оформление — библиотека компонентов MAX UI (React).
- Платежи и геолокация упоминаются в обзоре платформы, но в разделе мини-приложений
  не документированы. **Проверить руками до того, как закладывать в сценарий.**

## Боты

- Создание бота — через доступный команде официальный путь на платформе MAX; [инструкция](https://dev.max.ru/docs/chatbots/bots-create/create). Доступ студенческой команды уточняется у организаторов. Ник согласовать до создания: по ограничениям трека его нельзя изменить.
- Для получения событий из группового чата боту нужны права администратора. Возможность приёма и отправки проверяем в тестовом чате при подключении; методы и источники — в [спецификации интеграции](engineering/03-max-integration.md).
- События на итоговом стенде — через Webhook. Long Polling используется только в разработке/тестировании без активного webhook; детали сохранения событий и marker — в технической спецификации.
- Для Python используем документированный HTTPS Bot API и собственный тонкий HTTPX-клиент. Официальная [OpenAPI-спецификация](https://dev.max.ru/docs-api) служит источником форматов; отдельный сторонний SDK не является зависимостью проекта.

## Подключение и публикация

- Официальная инструкция на дату проверки допускает верифицированные профили юрлиц, ИП и самозанятых — резидентов РФ. Это не означает, что команда уже получила доступ.
- Текущие поля карточки, процедуры проверки и модерации сверяем при регистрации по [инструкции создания](https://dev.max.ru/docs/chatbots/bots-create/create), не используем прежние числовые ограничения как проверенные.
- Правила размещения, пользовательские документы и обработку данных проверяем перед публикацией по разделу правил [официальной документации](https://dev.max.ru/docs).
- Токен хранится вне Git и передаётся только серверным адаптером. Подробности авторизации и TLS — в [спецификации MAX](engineering/03-max-integration.md).

Внешняя зависимость проекта — фактическое разрешение на создание и демонстрацию бота. Проверяем её в S0, одновременно с тестовым чатом и личными сообщениями.

## Что это значит для архитектуры

- Точка входа — бот-администратор в тестовом групповом чате дома; личные опросы, карточки и PDF работают через Bot API без мини-приложения.
- Официальный домовой чат принадлежит ГЖИ, добавить туда своего бота можно только
  с согласия владельца. На демо используем собственный тестовый чат; в продукте заходим
  через регион, для существующих неофициальных чатов — через deeplink.
- Юридически значимое обращение отправляет бот «Госуслуги Дом» / ГИС ЖКХ. Мы не подменяем
  государственную систему, а доводим дом до неё и формируем пакет документов.
